# Tamil Nadu Engineering Admission Assistant

A simple web application that calculates a student's **TNEA engineering cut-off** and shows colleges with reference cut-offs within **±10 marks** of the calculated score.

## ✨ Features

* Calculate TNEA cut-off out of 200
* Find colleges within ±10 marks of the calculated cut-off
* Input validation
* Displays college name, TNEA code, location, and reference cut-off
* Responsive design
* Reset functionality

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🧮 Calculation

```text
Cut-off = Mathematics + (Physics / 2) + (Chemistry / 2)
```
